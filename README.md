# 鉅亨1212優惠大活動

- `index.html`：公開活動網站（GitHub Pages）
- `admin.html`：活動後台儀表板（需後台密碼）
- 後端程式在 Google 試算表「鉅亨1212活動後台」的 Apps Script（不放在公開 repo，以免後台密碼外流）

## 名額規則
- 試算表「名額連結」一列 = 一個名額 = 一條專屬付款連結
- 狀態：空白=可搶／備用=候補／已配發／已付款／逾時
- 搶到後 30 分鐘內未勾「已付款」→ 逾時，自動啟用一條同方案的備用連結
